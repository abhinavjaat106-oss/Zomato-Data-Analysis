Zomato Restaurant Data Analysis

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) of the Zomato restaurant dataset to understand restaurant trends, customer ratings, pricing, cuisines, and online ordering facilities in Bangalore.

Objectives
- Analyze restaurant distribution across different locations.
- Identify the most popular cuisines.
- Understand customer rating patterns.
- Analyze restaurant pricing and cost categories.
- Study online ordering and table booking trends.
- Explore relationships between votes and ratings.

Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

Dataset Information
- Original Dataset: 51,717 rows and 17 columns.
- Cleaned Dataset: 51,148 rows and 14 columns.
- Rows Removed: 569.
- Missing values in the rating column were retained for appropriate analysis.

Key Analysis
1. Restaurant distribution by location.
2. Most popular cuisines.
3. Online ordering analysis.
4. Table booking analysis.
5. Customer rating distribution.
6. Cost category analysis.
7. Location-wise average ratings.
8. Restaurant type analysis.
9. Votes vs customer ratings.

Key Business Insights
- Around 59.26% of restaurants support online ordering.
- Only 12.61% of restaurants provide table booking.
- Expensive restaurants have the highest average rating (4.13).
- North Indian cuisine is the most frequently listed cuisine.
- BTM has the highest number of restaurant listings (5,071).
- Restaurants offering table booking have a higher average rating.
- Votes and ratings show a moderate positive correlation (0.435).
